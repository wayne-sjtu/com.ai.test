# debugging — 调试排查技能

## 流程

1. **收集证据**：完整读取错误信息/堆栈，定位到具体文件与行号，先读代码再下结论。
2. **建立假设**：列出 1-2 个最可能的原因，说明判断依据。
3. **最小验证**：
   - 后端：`./mvnw clean compile` 区分编译期/运行期错误；启动后 curl 验证。
   - 前端：`npm run build` 看 tsc 报错；`npm run dev` 看运行时报错。
   - 更多排查手册：`docs/reference/troubleshooting.md`（常见问题卡住时读取）。
4. **修复**：改动最小化，只修问题本身，不顺手重构。
5. **回归验证**：确认原始操作已恢复正常。

## 原则

- 不猜测式连环修改；每个假设都要有验证手段。
- 修不了时向用户说明卡点与已排除的原因，而不是继续盲试。
- 涉及环境问题（端口占用、依赖下载失败等）优先检查环境而非代码。
