# 代码模板（按需加载）

| 模板 | 用途 |
|------|------|
| [controller.java.tmpl](controller.java.tmpl) | 后端 REST 控制器 |
| [service.java.tmpl](service.java.tmpl) | 后端服务层 |
| [Component.tsx.tmpl](Component.tsx.tmpl) | 前端 React 组件 |
| [api-service.ts.tmpl](api-service.ts.tmpl) | 前端接口调用封装 |
