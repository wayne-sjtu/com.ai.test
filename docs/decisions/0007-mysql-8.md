# ADR-0007：数据库选型 MySQL 8

- 状态：已接受
- 日期：2026-09-15

## 背景

平台引入数据层（此前无数据库依赖）。赛题允许自选数据库/中间件，需在交付文档中声明并锁定版本。

## 决策

MySQL 8（InnoDB）。

## 理由

- InnoDB 行锁（`SELECT ... FOR UPDATE`）天然支撑产品额度占用/扣减与幂等控制的演示
- 种子数据 SQL 生态成熟，评委代码走查认知负担最低
- 团队熟悉度与社区资料充足

## 后果

- 种子数据、建表脚本、docker-compose 镜像版本须锁定并写入设计文档部署声明
- 不使用 PostgreSQL 特有能力，避免迁移心智负担
