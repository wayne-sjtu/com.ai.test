# ADR-0006：简化账务模型（资金账户 + 幂等流水 + 份额持仓）

- 状态：已接受
- 日期：2026-09-15

## 背景

端到端主链路要求完整体现申购、赎回中的资金与份额变化，满足幂等、可追溯、账实一致。候选：完整复式账务（分户账、分录、日结）；简化账务。

## 决策

采用简化账务模型，三个核心实体：

- **资金账户**（customer_capital_account）：客户资金余额（可用/冻结）
- **资金流水**（capital_flow）：每个资金动作一条记录，幂等键 = 订单号 + 动作类型，同一动作不重复入账
- **份额持仓**（position）：客户产品份额账实记录

三者通过订单号关联，支持三方核对。

## 理由

- 命题明确"账户模型由参赛队自行设计"，考察点是幂等、留痕、账实一致，而非复式记账本身
- 幂等键直接支撑差错矩阵中"重复提交/重复回调"场景的可演示拦截
- 48 小时赛制下把工时留给交易状态机与异常处理

## 后果

- 非严格复式记账，日终对账以"订单-流水-份额"三方核对替代试算平衡
- 若后续引入真实总账对接，需在流水层之上补分录映射
